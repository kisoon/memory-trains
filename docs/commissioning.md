# 현장 시험 순서

## 1. 로직·핀 검증

모터·LED 전력부를 분리한 상태에서 ESP32-S3와 센서만 연결합니다. 실제 보드 회로도와 GPIO를 대조하고 USB와 외부 5V의 동시 공급은 보드의 역전류 보호 구성에 맞춰 처리합니다.

부팅 시 PWM/LED가 LOW인지 확인합니다. 센서를 손으로 가렸다 열어 homeActive, filmPulses가 올바르게 바뀌는지 확인합니다. 필요하면 ACTIVE_LOW를 바꿉니다.

바퀴 원판을 정확히 한 바퀴 돌려 wheelPulses가 실제 슬롯 수와 같은지 확인합니다. 축 흔들림과 슬릿 모서리에서 중복 펄스가 생기는지 함께 봅니다.

## 2. 오디오

5V 앰프 전원, 3.3V I2S, 올바른 스피커 연결을 확인합니다. 시험용 WAV로 음원 1/2 선택, 정지, 반복, 음량을 확인합니다. 낮은 음량부터 시작합니다. 파일 형식과 SD 상태가 오류이면 해당 음원을 사용하는 장면의 준비가 거부됩니다.

## 3. LED

실제 12V LED의 전류 제한 방식을 확인하고 전력부를 연결합니다. GPIO에는 전원 전압이 유입되지 않게 합니다.

필름 센서에 10Hz, 12Hz 등 시험 입력을 주고 LED 지연/점등시간을 오실로스코프로 확인합니다. 소리 재생과 Wi-Fi 요청이 동시에 있어도 최대 지터와 누락 수가 허용 범위인지 측정합니다. LED 게이트 파형과 실제 광출력은 차이가 있으므로 가능하면 포토다이오드로 빛도 확인합니다.

감지 주기보다 지연+점등시간이 길면 이벤트가 누락됩니다. 설정을 늘려 밝기를 올리기 전에 필름 투사 위치와 번짐을 함께 확인합니다.

## 4. 모터

차륜을 띄우고 PWM을 낮게 시작하여 방향을 확인합니다. 정방향 물리 방향이 반대이면 MOTOR_INVERT 또는 모터 배선을 수정합니다.

무부하·정상 부하·기동 전류를 확인합니다. 구속 전류는 제조사 자료 또는 전류 제한을 갖춘 적절한 시험 방법으로 확인합니다. 고의로 장시간 구속시키지 않습니다.

PWM이 0이 된 후 방향이 바뀌는지, 250ms 방향 전환 대기가 충분한지 확인합니다. 전원 전압이 회생 제동 시 드라이버 정격을 넘지 않는지 확인합니다.

## 5. 원점과 통신

레일에 원점 표식을 고정하고 HOME_PWM을 실제 최저 안정 속도에 맞춥니다. 표식 폭은 센서의 5ms 안정 감지와 제동거리를 확보해야 합니다.

원점 밖 부팅, 원점 위 부팅, 정상 복귀, 표식 가림 지속, 표식 제거의 다섯 조건을 시험합니다. HOME_STUCK/HOME_TIMEOUT 시 출력이 정지하고 자동 재출발하지 않는지 확인합니다.

수동 이동 중 PC 서버를 종료하거나 Wi-Fi를 끊어 3초 감시 정지를 시험합니다. 브라우저만 닫으면 서버가 계속 동작하므로 전시는 계속되는 것이 정상입니다.

정지 접점을 사용하면 단선도 정지 상태로 감지하는 NC 배선을 시험합니다. 웹 정지 버튼은 물리 비상정지 회로를 대체하지 않습니다.

## 6. 두 열차

각 열차에 다른 TRAIN_ID와 키를 업로드했는지 확인합니다. 둘 모두 원점 복귀 후 한 회차를 실행합니다.

처음에는 반복을 끄고 아래 항목을 측정합니다.

- 시작 시각 차이
- 두 레일의 실제 한 바퀴 시간
- 저속·고속에서 필름 정렬과 번짐
- 음원 시작 지연과 반복 경계
- 영상만 암전했을 때 모터·소리 유지
- 두 열차가 모두 복귀한 뒤 반복 대기
- 한 열차가 연결되지 않을 때 전체 시작 거부
- 한 열차 오류 시 다른 열차도 정지

검증 후 AUTO_HOME_ON_BOOT를 켜고 충분한 반복 운전으로 전원 안정성·발열·오디오 잡음·센서 오염 영향을 확인합니다. 특정 위치에서 두 투사 화면이 항상 겹쳐야 한다면 위치 기준점과 폐루프 제어를 추가해야 합니다.
