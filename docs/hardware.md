# 부품 선정·배선 초안

2026-10-11 공식 제조사 자료 확인. 실제 보드명, 모터 기동/구속 전류, LED 소비전력이 아직 제공되지 않아 전원·퓨즈·MOSFET 정격은 확정하지 않았습니다.

## 모터 드라이버 비교

| 모델 | 제조사 사양 | 장점 | 유의점 |
|---|---|---|---|
| Pololu G2 24v13 | 6.5–40V 절대최대, 권장 최대 약 34V; 연속 13A 조건부; 33.0×20.3mm | 작고 24V 전원 여유, 3.3V 지원, 전류감지·전류제한·역극성 보호 | 기본 전류제한 30A가 작은 모터 보호값인 것은 아님 |
| Cytron MD13S | 6–30V; 25°C 조건 연속 13A; 피크 30A/10초; 3.3V 지원 | PWM/DIR 단순, 보급형 대안 | 24V에서 회생 전압 여유가 작으므로 전원 구성 확인 |

13A 수치는 모든 방열·밀폐 조건에서 보장되는 운용 전류가 아닙니다. 모터의 정격·기동·구속 전류를 확인한 뒤 드라이버, 전류 제한, 퓨즈를 선정합니다. 회생 제동을 사용하는 전원은 순간 전압 상승을 흡수할 수 있어야 합니다.

Pololu PWM=LOW는 브레이크, SLP=LOW는 드라이버 절전입니다. 이 코드의 일반 정지는 PWM=0 브레이크이며 fault는 SLP를 LOW로 내려 출력 비활성화합니다. 따라서 고장 정지 시 관성으로 움직일 수 있습니다. 물리 정지는 별도 현장 회로와 기구로 확인합니다.

MD13S로 변경할 경우 MOTOR_SLEEP_PIN=-1, MOTOR_FAULT_PIN=-1. PWM/DIR는 유지하며 실제 정지 동작을 별도 시험합니다.

## 바퀴 속도 센서

첫 시험안은 **TCST2103 + 20슬롯 원판**입니다. 원판은 바퀴 축에, 센서는 차체에 고정하여 함께 이동하게 만듭니다. 원판과 센서는 차량 내부에 있으므로 레일별 장치를 추가하지 않아도 됩니다.

원판 두께와 흔들림을 고려해 3.1mm 센서 틈 안에서 비접촉으로 회전하게 합니다. 1mm 불투명 원판은 출발점이며 실제 출력물의 강도·적외선 차단 여부를 시험해야 합니다. 3D 프린트 소재는 눈에 검게 보여도 적외선을 통과시킬 수 있습니다.

- 슬롯 수는 20개를 예시로 사용하며 WHEEL_PULSES_PER_REV에 실제 FALLING 에지 수를 입력합니다.
- 바퀴가 1회전할 때 20펄스라면 RPM = 초당 펄스 수 × 60 / 20.
- 기어 전단 축에 원판을 설치하면 감속비를 포함해 바퀴 1회전당 펄스 수를 다시 계산해야 합니다.
- 단일 센서로는 회전 방향을 판별하지 않습니다. A/B 위상 센서 두 개가 필요합니다.
- 현재 코드는 측정값 표시용입니다. 피드백 속도 제어는 아직 없습니다.
- 바퀴 회전은 미끄러짐을 포함할 수 있으므로 절대 위치나 두 열차 간 실제 거리를 보장하지 않습니다.

## 센서 배선

TCST2103은 저항과 배선이 없는 센서 소자입니다. 제조사 패키지 도면에서 발광 다이오드 A/K와 수광 트랜지스터 C/E 핀을 확인합니다.

| 센서 부분 | 연결 |
|---|---|
| 발광 LED A | 3.3V → 직렬 저항 150Ω → A (시험 시작값, 실제 순방향 전압·전류 확인) |
| 발광 LED K | GND |
| 수광 E | GND |
| 수광 C | ESP 입력 + 외부 4.7kΩ으로 3.3V 풀업 |

이 회로는 빛이 통하면 LOW, 표식이 막으면 HIGH입니다. 따라서 기본 FILM_ACTIVE_LOW=false, HOME_ACTIVE_LOW=false입니다. 긴 배선·느린 경계에서 중복 펄스가 생기면 3.3V 슈미트 입력 버퍼로 신호를 정형하고 필요하면 소프트웨어 필터 시간을 조정합니다.

LM393 모듈형 센서는 공급전압과 출력 풀업이 제조사마다 다릅니다. VCC가 5V이고 OUT도 5V로 올라가는 모듈의 출력을 ESP32-S3에 직접 연결하지 않습니다. 모듈 회로를 확인하여 3.3V 풀업 또는 적절한 레벨 변환을 적용합니다.

원점 검출에는 ㄷ자 사이를 통과하는 고정 표식이 필요합니다. 투명 필름 자체의 차광 여부에 의존하지 않고, 필름의 위치를 나타내는 불투명 탭이나 검출 가능한 구멍 구조를 사용합니다.

## GPIO 예시

ESP32-S3-DevKitC 스타일 보드 기준. GPIO0/3/45/46 스트랩과 GPIO19/20 USB, GPIO35–37 일부 PSRAM 연결, 보드 LED GPIO38/48을 피한 예시입니다. 다른 ESP32-S3 보드에는 재배치가 필요합니다.

| 기능 | GPIO | 상대 연결 |
|---|---:|---|
| 모터 PWM | 4 | 드라이버 PWM |
| 모터 방향 | 5 | 드라이버 DIR |
| 모터 SLP | 15 | Pololu SLP |
| 모터 fault | 7 | Pololu FLT + 10kΩ 3.3V 풀업 |
| LED 제어 | 6 | MOSFET 게이트/드라이버 EN |
| 필름 감지 | 8 | 센서 C/정형 출력 |
| 원점 감지 | 9 | 센서 C/정형 출력 |
| 바퀴 감지 | 10 | 센서 C/정형 출력 |
| SD CS / MOSI / SCK / MISO | 11 / 12 / 13 / 14 | SPI microSD |
| I2S BCLK / LRCLK / DOUT | 18 / 21 / 47 | 앰프 BCLK / LRC / DIN |
| 앰프 mute | 16 | MAX98357A SD/MODE |
| 선택적 정지 접점 | 예: 17 | NC 접점 → GND, 열리면 HIGH; 기본 미사용 |

PWM과 LED 제어 신호에는 부팅 중 OFF를 유지할 외부 풀다운을 둡니다. 예: PWM 10kΩ, LED 게이트 100kΩ. MOSFET 구동 시 직렬 게이트 저항은 약 100Ω을 시험 출발값으로 둘 수 있지만 게이트 용량과 드라이버에 따라 조정합니다.

## 전원과 LED

24V 공급을 모터 드라이버, 12V LED용 DC-DC, 5V 로직·오디오용 DC-DC로 분기합니다. 모터 전류가 센서·ESP32의 가는 GND 배선을 통해 돌아가지 않도록 전원 귀환 경로를 분리하고 공통 기준점에서 연결합니다.

12V LED가 전류 제한이 내장된 정전압 모듈이면 저측 N-MOSFET으로 스위칭할 수 있습니다. bare LED/COB라면 정전류 드라이버가 필요하며 가능하면 그 드라이버의 DIM/EN을 사용합니다. MOSFET의 문턱전압만 보고 3.3V 구동 가능 여부를 판단하지 말고, 해당 게이트 전압에서의 RDS(on) 보증값과 발열을 확인합니다.

Pololu 제조사는 드라이버 가까이에 수백 µF 이상, 공급전압보다 충분히 높은 정격의 벌크 커패시터를 권장합니다. 최종 용량과 과도전압 억제는 배선 길이·실측 잡음·회생 에너지에 따라 결정합니다.

MAX98357A 전원은 5V, I2S 입력은 3.3V입니다. 12V/24V를 앰프에 공급하지 않습니다. 스피커는 SPK+와 SPK− 사이에만 연결하며 SPK−를 GND에 연결하지 않습니다.
