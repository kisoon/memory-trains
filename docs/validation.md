# 검증 기록 — 2026-10-11

## 수행한 검증

실행 환경 연결 오류로 OS 명령 실행이 불가능했습니다. 대신 제공된 JavaScript V8 실행기에서 저장된 소스 문자열을 직접 불러와 다음 순수 로직을 확인했습니다. Node 내장 import는 시험용 함수로 주입했고, 파일시스템·HTTP·실제 브라우저를 실행하지 않았습니다.

- JavaScript 10개 파일: import 문맥을 제거한 구문 검사 통과.
- 통신 규약·조정기·가상 장치 테스트 10개: 통과.
- 장면 유지시간 holdMs와 LED durationMs의 충돌을 찾아 수정.
- 정상 동시 준비와 양쪽 원점 복귀 후 반복 대기 확인.
- 한 장치 arm/home 실패 시 양쪽 정지 확인.
- 미복귀 상태의 시작 거부 확인.
- 범위 밖 PWM·LED 값 및 공개 IP 거부 확인.
- 오래된 이동 명령이 최신 정지를 덮어쓰지 못하는지 확인.
- 가상 장치의 3초 heartbeat 정지 확인.

## 아직 수행하지 못한 검증

- Node.js에서 npm test 실행.
- 실제 HTTP 서버·브라우저 UI 통합 시험.
- Arduino ESP32-S3 펌웨어 컴파일 및 보드 업로드.
- I2S 청취, microSD 호환성, LED 광출력 및 타이밍 지터 측정.
- 실제 24V 모터와 12V LED 부하 시험.
- 실물 원점 정지·바퀴 회전수 보정.
- 두 열차 위치 동기화와 장시간 무선 안정성.
- GitHub Actions에서 실제 Node.js 테스트 및 ESP32-S3 컴파일 결과 확인.

GitHub Actions 워크플로를 소스와 함께 업로드합니다. 아래 상태는 초기 코드 업로드 시점이며 실행 결과 확인 후 갱신합니다.
