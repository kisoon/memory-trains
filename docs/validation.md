## 확인한 동작

- 장면 유지시간 holdMs와 LED durationMs가 별도로 전달됨.
- 잘못된 PWM·LED 설정·외부 IP 입력 거부.
- 두 열차가 원점에 도착하기 전 시작 거부.
- 같은 회차의 두 열차를 준비·예약 시작.
- 한 장치의 arm/home 실패 시 양쪽 정지.
- 두 열차 완료 후 함께 반복 대기.
- 가상 장치의 3초 heartbeat 감시 정지.
- 지연된 이전 이동 명령이 최신 정지를 덮어쓰지 못함.
- 웹 인증 키 검증, 설정 파일 저장·조회.
- 실제 HTTP 경로로 두 열차 예약 시작 후 정지하면 예정 시각이 지나도 이동하지 않음.

## 실제 장비에서 남은 검증

- 브라우저 화면의 시각적·사용성 검토.
- 실제 ESP32-S3 보드 업로드와 전원·Flash/PSRAM·USB 설정 확인.
- I2S 청취, microSD 호환성, 음원 반복 경계.
- LED 센서→점등 지연과 점등 폭의 광학 실측.
- 24V 모터·12V LED 부하, 전원 잡음·회생 전압·발열.
- 원점 정지 위치·센서 극성·바퀴 회전수 보정.
- 두 열차의 무선 지연·장시간 반복 운전.
- 실제 정지 접점과 통신 두절 시 출력 동작.

보드의 실제 메모리·핀 배치는 컴파일 대상의 기본 설정과 다를 수 있습니다. 컴파일 성공은 실물 동작 보장이 아닙니다. [현장 시험 순서](commissioning.md)에 따라 단계적으로 검증해야 합니다.
